# 4TVIBEZ MUSIC

A black-and-gold, Spotify-inspired music discovery and local playback website for 4TVIBEZ ENTERTAINMENT.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Current features
- Responsive desktop and mobile layout
- Black-and-gold 4TVIBEZ visual identity
- Add audio files from your device
- Play, pause, next, previous, seek and volume controls
- Shuffle and repeat controls
- Search tracks added during the current session
- Create temporary playlist labels

## Important
This is the first frontend milestone. Audio files are selected from the visitor's own device and are not uploaded to a server. Tracks and playlist labels are not saved between page reloads. Online accounts, cloud music storage, artist uploads, persistent playlists, and admin tools will be added in later stages with a backend and secure storage.

Only upload or distribute music you own or have permission to use.
