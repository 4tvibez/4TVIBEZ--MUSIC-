# 4TVIBEZ MUSIC

A black-and-gold, Spotify-inspired music discovery and playback website for 4TVIBEZ ENTERTAINMENT.

## Run locally
Open `index.html` in a modern browser, or use the VS Code Live Server extension.

## Current features
- Responsive desktop and mobile layout
- Black-and-gold 4TVIBEZ visual identity
- Add audio files from your device
- Save selected audio files in the browser using IndexedDB
- Reload your saved local music library when you return in the same browser
- Play, pause, next, previous, seek and volume controls
- Shuffle and repeat controls
- Search tracks in your local library
- Create playlist names saved in the same browser
- Remove tracks from your local library

## Important limitations
This is still a frontend-only milestone. Music is stored in the visitor's browser on their own device; it is not uploaded to 4TVIBEZ servers and cannot be shared with other listeners. Browser storage can be cleared by the user or limited by the device. Playlist names are saved, but adding individual songs to playlists is not implemented yet.

Online accounts, cloud music storage, public streaming, artist uploads, shared playlists, and admin tools require a backend and secure storage. Those are future stages.

Only upload or distribute music you own or have permission to use.
